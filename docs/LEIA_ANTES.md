# Como usar o pacote

O enunciado PDF contém os contratos R01–R20, a matriz T01–T20, entregáveis e rubrica. `src/legado.ts` é o código a estudar e refatorar. `tests/legado.test.ts` contém quatro testes iniciais. O diagrama editável do legado está em `docs/legado-uml25.drawio`; imagem PNG/SVG é somente para consulta.

Importante: erros ou comportamentos inadequados do legado não revogam os contratos do enunciado.
