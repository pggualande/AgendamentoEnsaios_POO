# Avaliação prática integradora — Laboratórios de Engenharia

Projeto legado TypeScript. Leia integralmente o enunciado PDF antes de modificar o código.

## Preparação

```bash
npm install
npm run typecheck
npm test
```

O projeto inicial é deliberadamente incompleto em relação aos contratos R01–R20; os quatro testes fornecidos caracterizam somente comportamentos válidos já existentes. Durante a refatoração, ajuste os testes de caracterização para preservar sua semântica sem exigir a API legada.

A solução final deverá conter `docs/decisoes.md`, `docs/uso-ia.md` e seu diagrama UML 2.5 editável e renderizado. Mantenha um histórico Git dos incrementos de trabalho. Não há exigência de banco de dados, rede real ou interface gráfica.
